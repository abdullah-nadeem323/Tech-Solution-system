# Tech-Solution-System  
## Employee Management System (C++)

## 📌 Overview
**Tech-Solution-System** is a C++ console-based Employee Management System developed to demonstrate core **Object-Oriented Programming (OOP)** concepts.  
The system manages employee information such as name, ID, salary, and performance while showcasing memory management techniques.

## 🎯 Purpose
This project is designed for **learning and academic purposes**, focusing on:
- Practical implementation of OOP concepts
- Understanding deep copy vs shallow copy
- Safe use of dynamic memory allocation
- Use of static and const class members

## 🧠 OOP Concepts Used
- Classes & Objects  
- Constructors and Destructor  
- Copy Constructor (Deep Copy)  
- Shallow Copy using pointers  
- Dynamic memory allocation (`new` and `delete`)  
- Static data members and static functions  
- Const member functions  
- Encapsulation and data hiding  

## ✨ Features
- Store employee details (Name, ID, Salary, Performance)
- Compare salaries between employees
- Apply bonus to salary and return a new employee object
- Track total number of employees using static members
- Demonstrate deep copy and shallow copy behavior
- Display detailed employee information

## 🛠️ Technologies
- **Language:** C++
- **Concepts:** Object-Oriented Programming, Memory Management
- **Platform:** Console Application
